# Лабораторная работа №2

Многостраничный сайт-портфолио.

## Страницы сайта
| Страница        | Файл            | Содержание                                                       |
|-----------------|-----------------|------------------------------------------------------------------|
| **Главная**     | `index.html`    | Приветствие, краткое «кто я», карточки-анонсы остальных разделов |
| **Обо мне**     | `about.html`    | Биография, чем занимаюсь, хобби, «Почему IT?»                    |
| **Мои проекты** | `projects.html` | Таблица учебных и личных проектов + описания                     |
| **Контакты**    | `contacts.html` | Email, Telegram, GitHub                                          |

## Соответствие требованиям

### 1. Количество страниц (3–5) ✅

**4 страницы** — `index.html`, `about.html`, `projects.html`, `contacts.html`.

### 2. Требования к HTML

#### 2.1. Использование блочных и строчных элементов ✅

**Блочные элементы:**
- `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<div>`
- `<h1>`, `<h2>`, `<h3>`, `<p>`, `<ul>`, `<li>`, `<table>`

**Строчные элементы:**
- `<a>`, `<span>`

#### 2.2. Ссылки (от 1 шт.) ✅

- Навигационное меню из 4 ссылок на каждой из 4 страниц
- Внешние ссылки в футере каждой страницы
- `mailto:` для Email, ссылки на Telegram и GitHub на странице «Контакты»
- Ссылки-иконки на репозитории GitHub в каждой строке таблицы проектов

#### 2.3. Картинки (от 1 шт.) ✅

- `images/avatar.jpg` — круглый аватар на главной странице

#### 2.4. Таблица (от 1 шт.) ✅

Таблица на странице `projects.html`:

| Столбец    | Содержимое                              |
|------------|-----------------------------------------|
| Проект     | Название                                |
| Технологии | Стек                                    |
| Статус     | Завершён / В разработке / Запланировано |
| GitHub     | Ссылка на репозиторий                   |
| Год        | Год работы                              |

### 3. Требования к CSS

#### 3.1. Отдельный подключаемый файл ✅

Все стили вынесены в один файл `css/style.css`, подключаемый через `<link rel="stylesheet" href="css/style.css">` в `<head>` каждой страницы.

#### 3.2. Как минимум 3 вида селекторов ✅

Используются слдующие виды:

- Тег
- Класс
- ID
- Потомок
- Псевдокласс
- Псевдоэлемент

#### 3.3. Использование цвета ✅

#### 3.4. Различные виды выравнивания в таблице ✅

Все три вида выравнивания реализованы через отдельные классы:

| Класс         | Выравнивание    | Столбец                          |
|---------------|-----------------|----------------------------------|
| `.col-left`   | по левому краю  | «Проект»                         |
| `.col-center` | по центру       | «Технологии», «Статус», «GitHub» |
| `.col-right`  | по правому краю | «Год»                            |

### 4. Запрет на JS и фреймворки ✅

Всё сделано на чистом HTML и CSS.
