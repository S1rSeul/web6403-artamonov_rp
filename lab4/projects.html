О чем проекты

Сайт-портфолио

Мы сейчас тут 😊. Разрабатывается в рамках курса Web-разработка.

FloWe Backend

Серверная часть мобильного приложения, которое помогает парам быть на одной волне и проще организовывать совместную жизнь. Разрабатывается в рамках курса МРСИИ.

FoundIt

Серверная часть веб-приложения, которое помогает людям находить потерянные вещи и возвращать найденные владельцам. Будет разрабатываться в рамках курса «Технологии сетевого программирования».

Comment-Post Service

Небольшой CRUD-микросервис для киберспортивного новостного портала. Разрабатывался в рамках производственной практики.

MET ETL

Утилита командной строки для скачивания, обработки и анализа изображений из открытой коллекции Метрополитен-музея. Разрабатывалась в рамках курса «Технологии программирования на Python».

WearMe Backend

Первый крупный командный проект. Серверная часть мобильного приложения для облегчения подбора одежды по меркам пользователя. Разрабатывался в рамках курса «Операционных систем».

Web Fishing Script

Сомнительный скрипт для сомнительной игры. Ну зато теперь оно играет само в себя. Разрабатывался для личного интереса.

Swing

Пачка мини-проектов различного рода с использованием Java Swing. Разрабатывалась для самообразования.
